# HANDOFF — как продолжить работу

## Типовые задачи

**Поправить текст озвучки или субтитров**
1. Измените `content/<id>.json` (поле `text` нужного языка; числа пишите словами — так их правильно читает диктор;
   `caption`/`note`/`labels` — надписи на экране).
2. `python3 tools/tts.py <id> <lang>` — перегенерируются только изменённые сцены (кэш по хэшу текста).
3. `python3 tools/qa_audio.py <id> <lang>` — если WER > 0.15, `python3 tools/fix_audio.py <id> <lang> <scene> 2`.
4. `cd remotion && node render.mjs <id>-<lang>` → `out/`, затем `python3 tools/qa.py`, скопировать в `videos/`, закоммитить.

**Поменять голос** — `tools/voices.json` (`voice_id` из аккаунта ElevenLabs; модель `eleven_v3`, поддерживает кыргызский).
После смены голоса запустите `python3 tools/tts.py all` (кэш инвалидируется автоматически).

**Поправить анимацию** — `remotion/src/videos/<id>.tsx`; правила и инструменты в `docs/SCENE_AUTHORING.md`.
Проверяйте кадры через `node stills.mjs` или `npx remotion studio`.

**Добавить музыку/эффекты** — по умолчанию музыки нет (так просили). При необходимости добавьте `<Audio>` с лицензионно
чистым файлом в `components/VideoShell.tsx` с громкостью ≈ 0.08–0.12, чтобы не мешать речи.

**Публикация** — не публиковать без решения заказчика. Перед публикацией: проверка учёным (`docs/SOURCES_AND_REVIEW.md`),
прослушивание кыргызской озвучки носителем, подтверждение функций платформы командой Zeket (ролики №5, №6, №9).

## Известные ограничения
- Сетевая среда этой сессии не открывала muftiyat.kg, quran.com, sunnah.com — цитаты надо сверить по ссылкам в
  `docs/SOURCES_AND_REVIEW.md`.
- Кыргызское произношение проверено только автоматически (речь → текст). Слова, к которым стоит прислушаться,
  перечислены в `STATUS.md`.
- Создание GitHub Releases из этой среды запрещено, поэтому MP4 лежат прямо в `videos/` (≈11 МБ каждый).
- Лицензия Remotion: бесплатна для физлиц и организаций до 3 человек; крупнее — нужна компания-лицензия
  (https://remotion.dev/license).

## Структура кода Remotion (кратко)
- `Root.tsx` регистрирует 18 композиций из `videos/index.ts` (данные) и `videos/registry.ts` (сцены).
- `components/VideoShell.tsx` — последовательность сцен с кроссфейдом, аудио каждой сцены, субтитры (`Subtitles.tsx`).
- `components/anim.ts` — `wordFrame(scene, "слово")` даёт кадр, когда диктор произносит слово: так синхронизируются надписи.
- `illustrations/` — плоские SVG-примитивы (горы, юрта, дом, люди в калпаке/элечеке, монеты, весы, книга, телефон...).
