# Визуальная система

**Настроение.** Спокойно, тепло, с уважением. Плоская 2D-графика с мягкими пружинными появлениями, медленным дрейфом
камеры и постоянным лёгким движением (покачивание деревьев, парение монет, лучи солнца).

**Цвета** (`remotion/src/theme.ts`). Бренд-зелёный Zeket `#006633` и золото логотипа `#E0A93A` — акценты; фон кремовый
`#FAF6EE`; мята `#DFEFE4`; терракота `#C9774B` — тёплый акцент (крыши, плашки «Пример»); ночь `#1E2E4A`; горы `#7E9AAE`.
Кожа персонажей — три оттенка. Логотип — настоящий, с zeket.kg (`remotion/public/brand/zeket-logo.png`).

**Шрифты.** Nunito (800–900) — заголовки и цифры; Inter (500–700) — субтитры и мелкий текст. Оба поддерживают ү, ө, ң.

**Сетка 1080×1920.** Верхняя безопасная зона 0–190, подпись/заголовок 230–400, иллюстрация 430–1230, пилюля-источник
≈1140–1210, субтитры ≈1270–1500 (белый текст на тёмно-зелёной плашке, 48 px, максимум 2 строки, текущее слово подсвечено
золотом), нижняя безопасная зона 1500–1920. Боковые поля 64 px. Все важные слова и числа ≥ 44 px.

**Персонажи.** Простые фигуры с круглой головой, улыбкой, калпаком/элечеком/платком; нуждающиеся показаны стоя, спокойно,
без поз мольбы. Нет изображений Аллаха и пророков; Коран — только как книга с орнаментом без арабского текста.

**Кыргызский контекст.** Ала-Тоо со снежными вершинами, юрта, сельские дома, базар, поля Чуйской долины, арыки, дасторкон.

**Переходы.** Кроссфейд 10 кадров между сценами, плавный уход в фон в конце. Каждая сцена — своя композиция
(улица / ночь / абстрактный фон / схема), чтобы ролик не выглядел слайд-шоу.

**Звук.** Только голос (ElevenLabs v3: кыргызский — женский голос-рассказчик из аккаунта, русский — мужской спокойный
голос). Музыки нет по требованию заказчика; интегральная громкость ≈ −14…−16 LUFS.
