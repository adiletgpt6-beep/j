# HANDOFF — как продолжить видео «Али ибн Абу Талиб»

## Где что лежит
| Путь | Что |
|---|---|
| `projects/ali/script.ky.json` | Текст озвучки по сценам. `display` задаёт, как произнесённые числа показываются в субтитрах («он үч» → «13»). `\|\|` в тексте — намеренная пауза (`chunk_gap_s`). `test: true` — сцена тестового фрагмента. |
| `projects/ali/voice.json` | Голос ElevenLabs (`voice_id`, модель `eleven_v3`, `language_code: ky`), паузы, параметры субтитров. **Голос ещё не выбран**: кандидаты перечислены в `_comment`. |
| `projects/ali/tools/build.py` | Сборка данных: озвучка → тайминги слов → фразы субтитров → `remotion/public/ali/data/*.json` и `projects/ali/subtitles/*.srt`. |
| `remotion/src/ali/kit.tsx` | Графика: комната, дасторкон, лампы, свет, пыль, фигуры без лиц, мальчик со спины, камера, грейдинг, заголовки. |
| `remotion/src/ali/scenes.tsx` | Сцены. Готова `S10First`, остальные пока `PendingScene`. Синхронизация через `wf(scene, "слово")`. |
| `remotion/src/ali/AliShell.tsx` | Сборка сцен, озвучка, атмосфера (`room.mp3` в цикле), субтитры. |
| `remotion/render-ali.mjs` | Рендер: `node render-ali.mjs ali-test` или `node render-ali.mjs ali` → `out/<id>.mp4`. |
| `projects/ali/renders/` | Промежуточные и финальные MP4. |

## Шаги
```bash
cd remotion && npm ci                                # один раз
python3 projects/ali/tools/build.py                  # бесплатно: оценочные тайминги (без озвучки)
python3 projects/ali/tools/build.py --tts test       # ПЛАТНО: озвучка только тестовой сцены (~150 знаков)
python3 projects/ali/tools/build.py --tts full       # ПЛАТНО: весь ролик (~1350 знаков), кэш по хэшу текста
cd remotion && node stills.mjs ali-test 120,300,420 /tmp/st   # кадры для проверки
node render-ali.mjs ali-test                         # MP4
```
После озвучки метка «ОЗВУЧКА ЖОК» исчезает сама: при `hasAudio: true` все анимации привязаны к реальным
таймингам слов.

## Правила изображения (не нарушать)
- Пророка ﷺ не изображать никак. Только свет (`HolyLight`) во главе дасторкона.
- Али только со спины (`BoyBack`) или детали: рука, кувшин. Лица нет.
- У остальных фигур (`Seated`) нет глаз и рта.

## Риски по озвучке
- Голоса этого аккаунта ранее произносили «кантип» как «кандай тип». В сцене 13 есть «Кантип жетпей койсун?!»:
  проверить на слух. При ошибке переформулировать, например «Албетте, жетти!», но только с согласия заказчика.
- Проверить ударения: «Аркам», «Шуара», «Абу Лахаб», «Али ибн Абу Талиб», «саллаллаху алейхи ва саллам».
