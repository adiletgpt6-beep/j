# START HERE — Zeket explainer videos

**Что это.** Серия из 9 анимационных роликов (вертикальные 9:16, 1080×1920, 30 fps, H.264 + AAC) о закяте и садаке
для платформы Zeket (zeket.kg). Каждый ролик существует в двух версиях — кыргызской (`ky`) и русской (`ru`) — со своей
озвучкой и субтитрами. Итого 18 видео.

**Где что лежит.**

| Путь | Что там |
|---|---|
| `content/*.json` | Сценарии: текст озвучки (ky/ru), подписи на экране, визуальный бриф каждой сцены. Единственный источник правды для текста. |
| `tools/tts.py` | Озвучка через ElevenLabs (голоса из аккаунта, см. `tools/voices.json`) → `remotion/public/audio/`, тайминги слов → `remotion/public/data/`, субтитры → `subtitles/*.srt`. |
| `tools/qa.py`, `tools/qa_audio.py`, `tools/fix_audio.py` | Техпроверка MP4, проверка речи распознаванием (WER), перегенерация неудачных реплик. |
| `remotion/` | Проект Remotion (React). `src/videos/<id>.tsx` — сцены каждого ролика, `src/illustrations` — библиотека иллюстраций, `src/components` — субтитры, подписи, анимация. |
| `remotion/render.mjs`, `remotion/stills.mjs` | Рендер MP4 / рендер кадров для проверки. |
| `videos/` | Готовые MP4 (хранятся в git, ~10–12 МБ каждый). |
| `subtitles/` | SRT-файлы для сайта / соцсетей. |
| `docs/VIDEO_REGISTRY.md` | Реестр всех 9 роликов × 2 языка со статусами. |
| `docs/SOURCES_AND_REVIEW.md` | Аяты, хадисы, данные Муфтията и вопросы к исламскому учёному — прочитать перед публикацией. |
| `docs/SCENE_AUTHORING.md` | Как устроены сцены и как добавлять/править анимацию. |
| `docs/RENDER.md` | Как перерендерить (пошагово). |
| `STATUS.md` / `HANDOFF.md` | Что готово, что осталось, как продолжить. |

**С чего начать.**
1. Прочитайте `STATUS.md`.
2. Скачайте видео из папки `videos/` (на телефоне: открыть файл в GitHub → кнопка «Download» / «Raw»).
3. Перед публикацией: отдать `docs/SOURCES_AND_REVIEW.md` и тексты из `content/` на проверку учёному и носителю
   кыргызского (послушать озвучку).
4. Для правок — `HANDOFF.md`.

**Секретов в репозитории нет.** Ключ ElevenLabs берётся из переменной окружения `ELEVENLABS_API_KEY`.
